# 固定基线：协议、结果与复现边界

正式评估发生于2026-11-01至11-02。所有评估均冻结模型、不训练；24×24地图、出生距离参数17、horizon 1024、CPU/fp32、双方argmax、`general_trade=True`，每图交换座位两局，8个评估lane。初批seed为930001，P2追加批为930002。

七组正式评估共1,600局，均无平局、无截断。初批五组使用相同地图和座位；P6使用与P2初批相同的100张图；追加200张图的初始地图hash与首批零重叠。地图hash去重不等同于验证所有旋转/镜像变体。

每张地图上的两局平均为一个[0,1]统计单元。区间半径为`sqrt(log(40)/(2*N))`，N为来源地图数。各对手单独报告；截断和真实平局在胜率中计0并分别列出，不合并不同对手的胜率。

**扩样是在看到首批122/200后决定的。** 合并区间沿用固定时点Hoeffding计算，没有可选停止校正，下界仅略高于50%；不能将合并结果包装成事先独立注册的确认试验。

共享100图、同座位比较：33/39都赢78局，仅33赢44局，仅39赢44局，都输34局；McNemar双侧精确检验p=1.000。它说明本批未发现表现差异，**不证明两者等价或已确定饱和**。39没有追加200图上的对应数据，也不能将33的58.17%套用给39。

## 原始材料与历史表述

`data/baseline/initial/`保存初批五组逐局JSON、原协议、adapter检查和独立核验记录；`extension/`保存追加P2、P6和原协议/核验。原结果字节及模型hash均由 [manifest.json](manifest.json)固定。

原协议是运行前冻结的历史文件，其中有后来修正的先验判断。例如初批协议的`known_caveat`不能作为最终“模型不占城”结论；复核显示33有占城记录但非常少。原协议中“从ppo20起训”的来源断言也不能替代33缺失的来源元数据。当前结论以本说明及实验数据为准。

归档保留了经济统计，但均值接近1不意味着每局每时点都没有城市；也不能由规则bot最终全败推断经济能力对其他对手不重要。

## 模型和依赖

使用已有的`iteration-00000033.zip`、`iteration-00000039.zip`和`ppo20.zip`；文件SHA256见 [manifest.json](manifest.json)。权重未包含在本PR中，目前没有公开下载地址，需要向项目维护者取得相同快照。它们是actor策略快照，不是可恢复训练的完整checkpoint。

新增工具复用仓库中的`agents/1014`，不会复制或修改默认训练代码。历史本地版本仅将评估器的一步逻辑提取为`_tick`，并为训练环境增加课程支持；基线所用观测、地图生成和模型主体保持一致。本PR用P2/P5各两局完整对战验证兼容性，未重新执行全部1,600局。

CPU环境安装和逐配对运行命令见 [工具说明](../../../experiments/baseline/README.md)。即使未取得权重，也可以用标准库运行`verify.py`核对归档数据。硬件和依赖版本变化可能影响浮点结果；新评估必须保存为新文件，不能覆盖归档。
