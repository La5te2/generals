### 2025 年方案

[Artificial Generals Intelligence: Mastering Generals.io with Reinforcement Learning](2507.06825v2.pdf) 第 5 至 6 页介绍了先模仿、再强化的路线。论文从约 347,000 场回放中筛选出 16,320 场对局，用行为克隆初始化 U-Net 策略，再以 PPO 对抗由 3 个历史策略组成的对手池。候选策略达到评估标准后替换最早的对手。

为增加过程反馈，论文使用领土、兵力和城市的相对优势构造势函数：

$$
\begin{aligned}
r_t^{\mathrm{shaped}} &= r_t^{\mathrm{game}} + \gamma\Phi(s_{t+1}) - \Phi(s_t) \\
\Phi(s) &= 0.3f_{\mathrm{land}}(s) + 0.3f_{\mathrm{army}}(s) + 0.4f_{\mathrm{castle}}(s)
\end{aligned}
$$

各分量使用归一化对数比值，相邻状态的势差把物质优势的改善转为奖励。论文报告的强化学习阶段使用 1 张 H100，训练约 36 小时，其核心组合是高手示范、空间卷积、历史对手池和奖励塑形。

### 2026 年方案

[Superhuman AI for Generals.io Using Self-Play Reinforcement Learning](2606.23348v1.pdf) 第 4 至 6 页与附录介绍了从随机策略开始的稀疏奖励自对弈。主要实验使用 4 张 H200 训练约 4 天，将全 JAX 训练流程与以下机制结合：

| 机制              | 论文配置                                                     |
| ----------------- | ------------------------------------------------------------ |
| Patch Transformer | $3\times3$ patch、7 层、448 维、8 头，约 15.35M 参数         |
| 观测与记忆        | 38 个空间通道，敌方兵力和领土各 512 步历史，分别汇聚为一个 token |
| 出生距离课程      | BFS 距离上限从 4 开始逐渐扩大，直到覆盖完整游戏分布          |
| HL-Gauss 价值头   | 128 个桶覆盖 $[-1,1]$，平滑目标分布配合分类损失              |
| 优势筛选          | 按预测优势排序，选择每批前 25% 转移用于策略梯度更新          |
| EMA               | 参数衰减为 $0.999$，部署使用平均权重                         |

出生距离课程增加随机策略早期获得胜负反馈的机会，高吞吐采样提供训练规模，优势筛选和 EMA 则改善训练效率与部署表现。这些机制的收益来自论文报告的实验条件。
